# Resume Pilot 桌面控制中心（v2 开发预览）

桌面端负责本地岗位库、简历条件排序、去重队列、按企业限额和按招聘域名限速；浏览器插件继续负责使用真实浏览器登录状态进入官网、核验岗位、填写表单和让用户处理验证码。

当前开发预览版本：**2.0.0-alpha.2**，扩展内部版本为 `2.0.0.2`。本版包含岗位路由、队列保留、重连限流、资料同步和文件写入可靠性修复，并修正安装版共享评分文件的加载路径，避免安装后启动报错。

已验证：12 项桌面测试、6 组扩展逻辑测试、安装版桌面界面冒烟测试、安装版本地通信组件测试，以及隔离 Edge 配置中的扩展连接测试。测试没有真实提交求职申请，不等同于各招聘官网的完整投递验收。

## 从 alpha.1 升级

1. 关闭 Resume Pilot 桌面窗口，运行 `resume-pilot-desktop-2.0.0-alpha.2-setup.exe` 覆盖安装。保留原安装路径，继续使用已有本地数据。
2. 打开桌面快捷方式，左上角应显示 `RESUME PILOT 2.0.0-alpha.2`。
3. 在 Edge 的 `edge://extensions` 中对“简历领航”点击“重新加载”，使浏览器读取更新后的扩展。安装目录或仓库目录加载的扩展均需重新加载；其他位置的副本需更新对应文件。
4. 重新打开招聘网页，在扩展中点击“连接桌面端”，确认连接后先运行一条不提交的试运行。

安装版与开发预览仍有下述功能边界；GitHub 源码更新不代表公开 Release 安装包同步更新。

## 本地运行

在仓库根目录执行：

```powershell
npm install
npm run desktop:dev
```

开发时可设置 `RESUME_PILOT_DATA_DIR`，将测试数据固定保存在项目的 `tmp` 目录。生产安装包将使用应用自己的用户数据目录。

## 普通用户使用流程

1. 安装 `resume-pilot-desktop-*-setup.exe`；安装程序会按当前用户范围注册 Edge/Chrome Native Messaging 主机。
2. 在扩展中导入简历，设置目标岗位、城市、行业和待遇。桌面端目前只提供岗位、城市、行业、类型与技能输入；同步时会一并接收扩展的待遇条件。
3. 打开 Edge 的 `edge://extensions`，开启开发人员模式。安装版用户点击桌面端“打开扩展文件夹”，加载该目录；开发者加载仓库根目录。
4. 打开招聘官网，在扩展的“3. 填当前页”点击“连接桌面端”，确认显示“桌面控制中心已连接”。
5. 导入 PDF/DOCX 简历，检查识别结果，在“找企业”中确认岗位与城市条件。
6. 首次使用“试运行：填写但不提交”，最多处理岗位设为 1；确认无误后再选择确认提交或全自动模式。
7. 遇到登录、验证码或未配置必填项，处理后点击“处理后继续”；扩展不会绕过验证码或编造资料。

## 当前边界（请先阅读）

- “连接桌面端”只验证本地通信。还需点击扩展的“同步”按钮，将求职条件和岗位线索同步到桌面端；条件同步目前为扩展到桌面端单向同步。
- 桌面端“预览待核验岗位”只展示队列，不领取任务，也不会启动网页投递。桌面队列到扩展自动执行的接管链路尚未接通；官网运行仍须在扩展中启动。
- “重新生成队列”保留处理记录、处理中任务和重试等待，不会重新投递已提交或提交结果不明的岗位。每家企业上限也计入保留记录；队列上限限制本次新加入的岗位数。
- 浏览器宿主重连后会根据保存的任务状态和冷却时间继续等待。处理中任务不会被自动重投；异常中断后的人工核验与恢复入口仍待完善。
- 本地 JSON 写入已改为原子替换，单个宿主按顺序处理请求；多进程同时修改数据的事务隔离尚未实现。请避免在扩展同步期间同时修改桌面数据。
- 官网适配回归测试使用模拟页面，不代表已在所有真实官网成功提交。最新源码不会自动更新已安装的软件。

本次检查结果和后续优先级见 [RELIABILITY_REVIEW.md](RELIABILITY_REVIEW.md)。

## 当前功能

- 保存不含身份信息的求职条件。
- 导入插件同步或 JSON 格式的公开岗位元数据。
- 复用扩展的城市与岗位评分规则。
- 剔除地点、招聘类型、经验或截止日期不符合的岗位。
- 按最低分、总队列上限和每家企业上限生成队列。
- 同一招聘域名一次只处理一个岗位。
- 遇到 HTTP 429 时按域名指数退避，不连续刷新。
- 提供 Chrome Native Messaging 协议、主机实现和安装配置模板。

## 安全说明

- 插件同步前会剔除姓名、电话、邮箱、学校、简历正文、附件和已记住答案。
- v2 安装版将 Native Messaging 作为桌面通信所需权限；本地主机仍通过固定扩展 ID 白名单限制访问。
- 安装包只写入当前用户（HKCU）的 Edge/Chrome Native Messaging 注册项，不需要管理员权限；卸载时会删除本项目写入的注册项。
- Native Messaging 主机通过固定扩展 ID 白名单限制访问，安装包会同时放置主机程序和清单文件。
