# 简历领航 Resume Pilot

一个无需后端即可运行的 Chrome / Edge 扩展 MVP。它根据岗位、城市、行业和偏好企业搜索官网招聘入口，并在招聘申请页面上识别和填写常见字段。

## 已实现

- 粘贴简历文本，启发式识别姓名、手机号、邮箱、学校、专业、学历和毕业年份。
- 导入结构化 JSON，所有资料只存于 `chrome.storage.local`。
- 通过 Bing RSS 自动搜索企业与具体岗位，不需要 API Key。
- 内置腾讯、字节跳动、华为、阿里巴巴的已核验官方招聘域名作为搜索种子，同时继续发现其他企业官网。
- 根据岗位词、城市、技能、实习/校招类型、偏好企业和官网可信度计算 0–100 匹配分，并显示推荐依据。
- 在任意企业官网岗位列表页直接扫描可见岗位卡片，按简历条件重新排序；适合搜索引擎只返回招聘首页时继续使用。
- 过滤常见内容平台和部分第三方招聘平台，并按“官方、校招、招聘 URL”等信号排序。
- 自动识别并填写姓名、手机、邮箱、学校、专业、学历、毕业年份、城市和技能字段。
- 在网页右下角询问未知必填项，并把回答写回原表单。
- 标出已填写与未知字段，帮助逐项复核。
- 不自动点击最终提交、不绕过验证码。

## 安装

1. 下载或复制整个 `resume-pilot-extension` 文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本文件夹。
5. 将“简历领航”固定到工具栏。

## 使用

1. 打开扩展，在“我的资料”里粘贴简历文字，点击“识别常用信息”。
2. 检查识别结果，补充资料并保存。
3. 在“找企业”中填写目标岗位、城市、行业和求职类型。若已有心仪企业，可用逗号或换行填写名称。
4. 扩展会优先列出具体岗位；如果结果是招聘入口，打开企业官网岗位列表后点击“分析当前官网的岗位列表”。
5. 点击扩展的“填当前页” → “扫描并填写当前页面”。
6. 回到网页，在右下角回答未知必填项，逐项检查后亲自提交。

## 当前限制

- 首版不直接解析 PDF / DOCX；可从文件中复制文本，或使用 JSON 导入。
- 企业官网识别基于搜索结果与规则评分，不能保证每个结果都是官方域名，打开前务必核对。
- “优秀企业”没有统一客观定义；首版用已核验官网、用户偏好、岗位匹配和公开搜索信号排序，不对薪资、文化或发展前景作保证。
- 招聘系统差异很大；复杂的自定义控件、跨域 iframe、文件上传和动态问卷可能需要手动处理。
- 简历附件仍需用户手动上传；浏览器安全机制不允许扩展静默选择本地文件。
- 搜索依赖 Bing RSS 的可用性与返回质量。

## 分享与隐私

可以压缩整个文件夹发给别人，对方按“安装”步骤加载即可。个人资料不会随文件夹一起分享，因为它保存在每位用户自己的浏览器中。求职搜索会向 Bing 发送岗位、城市、行业和偏好企业名称，但不会发送姓名、电话、邮箱或完整简历。

## 后续适合增加

- 本地 PDF / DOCX 解析（打包 PDF.js 与 Mammoth）。
- 企业白名单、黑名单和官网域名确认缓存。
- 岗位收藏、投递状态看板、重复投递提醒。
- 为常见 ATS（如 Workday、Greenhouse、Lever）编写专用适配器。
- 可选的本地大模型字段匹配；默认仍不上传敏感资料。
