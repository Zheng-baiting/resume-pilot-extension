# 简历领航 Resume Pilot

一个无需后端即可运行的 Chrome / Edge 扩展。它先从简历推断多个合适的岗位方向，再逐个调用企业官网搜索与筛选，综合岗位、企业和待遇后运行自动投递队列。当前版本为 v0.5.0。

## 已实现

- 可粘贴简历文本，也可直接导入 JSON、PDF、DOCX、TXT 或 MD 文件；所有资料只存于 `chrome.storage.local`。
- 使用扩展内置的 PDF.js / Mammoth 在浏览器本地提取 PDF / DOCX 正文，不把简历上传到第三方解析服务。
- 导入 PDF / DOCX 时自动识别姓名、手机号、邮箱、学校、专业、学历和毕业年份，并把原文件保存为之后官网投递的附件。
- 通过 Bing RSS 搜索企业与具体岗位，不需要 API Key；即使搜索暂时失败，仍会显示内置官方岗位入口。
- 内置腾讯、字节跳动、华为、阿里巴巴、百度、京东、美团、小米、网易、大疆、OPPO、联想和招商银行等官方招聘域名，并继续发现其他官网。
- 企业结果分批加载；在扩展结果区向下滚动会继续追加下一批，不覆盖已经显示的结果。
- 将结果拆成企业质量、岗位匹配、待遇三个独立分数，并显示推荐依据、风险提示和证据充分度。
- 综合排序权重为企业质量 30%、岗位匹配 45%、待遇 25%。
- 支持最低日薪/月薪、每周到岗天数、可实习月数、经验上限和企业/岗位排除关键词。
- 企业质量可选择综合均衡、稳定优先、成长优先或学生培养优先。
- 待遇分识别公开薪资区间，以及奖金、五险一金、补贴、商业保险、住房、带薪假期和弹性工作等福利信号；没有公开待遇时采用保守分数。
- 自动判断当前是招聘介绍页、岗位列表页还是岗位详情页；介绍页会继续进入官方岗位列表。
- 根据目标岗位、专业、技能和项目经历生成最多 6 个岗位方向及匹配分；在自动投递区显示当前正在尝试的方向。
- 每家公司会逐个搜索这些岗位方向并汇总具体岗位，全部方向都失败后才进入下一家公司。
- 优先企业严格按照用户填写的顺序处理。
- 优先使用官网自己的关键词搜索与实习/校招类别控件，再自动翻完传统分页和无限滚动列表；官网筛选过严时会清空条件后完整扫描，不会直接跳到下一家公司。
- 扫描普通链接岗位和没有链接的 SPA“点击式岗位卡片”，按简历条件重新排序；已对华为动态岗位列表进行真实页面验证。
- 过滤常见内容平台和部分第三方招聘平台，并按“官方、校招、招聘 URL”等信号排序。
- 自动识别并填写姓名、手机、邮箱、学校、专业、学历、毕业年份、城市和技能字段。
- 首次导入或选择 PDF / DOCX 简历附件后，之后可在申请表中复用。
- 在网页右下角询问未知必填项，把回答写回原表单并记住；以后遇到同类问题自动复用。
- 标出已填写与未知字段，帮助逐项复核。
- 提供“开始全自动投递”按钮：按综合分选择岗位、打开详情、填写、提交、记录结果，再转向下一家企业。
- 详情页只有“申请”两个字时也能识别；必须确认已进入申请表才会填写和寻找最终提交按钮。登录完成后会自动检测跳转，若官网返回详情页则自动重新进入申请流程。
- 自动投递需要单独勾选最终提交授权，并可设置本次最多投递数量。
- 验证码策略可选“暂停找我处理”或“跳过当前岗位”；扩展不会破解或绕过验证码。
- 登录、未知必填项、无法可靠识别提交按钮时会暂停，不编造个人资料。

## 安装

1. 用 7-Zip 解压下载的压缩包，进入解压后的 `resume-pilot-extension` 文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本文件夹。
5. 将“简历领航”固定到工具栏。若此前装过旧版，在扩展管理页点击它的“重新加载”。

## 使用

1. 打开扩展，在“我的资料”里点击“导入简历文件”，选择 JSON、PDF、DOCX、TXT 或 MD；也可以直接粘贴简历文字。
2. PDF / DOCX 会自动读取正文并保存为投递附件。检查自动识别结果，补充没有识别到的资料后点击“保存资料”。
3. 在“找企业”中填写目标岗位、城市、行业、求职类型和最低待遇。若已有心仪企业，可用逗号或换行填写名称。
4. 展开“到岗能力与排除条件”，填写每周到岗天数、实习月数和不接受的关键词。
5. 点击“自动寻找合适企业与岗位”；向下滚动会持续加载下一批企业。打开某个结果后，也可点击“分析当前官网的岗位列表”。
6. 手动测试时，进入“填当前页”并点击“扫描并填写当前页面”；网页右下角会列出未知必填项。
7. 全自动测试时，先把“本次最多投递”设为 `1`，验证码选择“暂停找我处理”，勾选授权，再点击“开始全自动投递”。
8. 遇到新必填项，在网页右下角回答并点击“应用我的回答”；任务会记住答案并继续。遇到登录或验证码，处理完后点击“处理后继续”。

首次实验建议使用你愿意实际投递的岗位，并把上限设为 1。勾选自动提交后，扩展可能真的向企业发送申请。

## 支持的简历文件

- `.pdf`：提取可复制的文字，并保存原 PDF 作为投递附件。
- `.docx`：提取 Word 正文，并保存原 DOCX 作为投递附件。
- `.txt` / `.md`：读取纯文本，用于生成资料；需要另选 PDF / DOCX 作为投递附件。
- `.json`：导入完整的结构化资料，字段模板如下。
- `.doc`：旧版二进制 Word 格式暂不解析，请在 Word 或 WPS 中“另存为” `.docx`。

如果 PDF 中的文字无法选中，它通常是扫描图片。请先在 WPS、Adobe Acrobat 或其他 OCR 工具中识别文字并保存为“可搜索 PDF”，再导入本扩展。

## 当前限制

- PDF / DOCX 的文字提取依赖文档本身包含真实文字；扫描件、加密文件、损坏文件或非常规排版可能无法完整识别。
- 单个导入文件最大 5MB；`.txt`、`.md` 和 `.json` 不会自动成为官网投递附件。
- 内置企业入口会核验域名；搜索发现的其他结果仍可能判断错误，界面会显示置信度和风险提示。
- “优秀企业”没有统一客观定义。扩展将稳定与公开披露、成长与创新、学生培养、信息透明度分开评分；未进入核验库的企业会明确标为证据不足。
- 待遇判断只能使用岗位页面公开的薪资和福利文字，不能知道奖金实际发放、加班强度、团队氛围或最终 offer；这些必须在面试中核实。
- 招聘系统差异很大；跨域 iframe、复杂自定义控件、登录、短信验证和网站反自动化机制可能使任务暂停或跳过。
- 扩展不会识别或绕过验证码；即使选择“跳过”，也只是跳到下一岗位。
- “已提交待核验”表示扩展点击了提交按钮但页面没有出现明确成功文字，不能等同于企业已收到申请。
- 自动提交只能基于你提供的真实资料；未知项会暂停，不会猜测。
- 搜索依赖 Bing RSS 的可用性与返回质量。

## 分享与隐私

可以压缩整个文件夹发给别人，对方按“安装”步骤加载即可。个人资料、已记住的回答、简历附件和投递历史不会随文件夹一起分享，因为它们保存在每位用户自己的浏览器中。求职搜索会向 Bing 发送岗位、城市、行业和偏好企业名称；只有在填写/投递某个企业申请表时，个人资料才会进入该企业招聘页面。
